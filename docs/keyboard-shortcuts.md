# キーボードショートカット

アプリケーション内では、右上のヘルプボタン（**?**）または **H** キーでショートカットの一覧を表示できます。テキスト入力欄にフォーカスがあるときは、ショートカットは無効になります。

## シミュレーション

| キー | 操作 |
| --- | --- |
| `Space` | 一時停止 / 再開（CSV 再生中は CSV の再生 / 停止） |
| `R` | t = 0 に戻す（衛星を初期配置に戻す。CSV 再生中は再生を停止して先頭に戻す） |
| `+` / `=` | 時間倍率（CSV 再生中は再生速度）を 1 段階上げる |
| `-` / `_` | 時間倍率（CSV 再生中は再生速度）を 1 段階下げる |
| `F` | 「衛星配置」タブを開く（CSV 再生中は無効） |

## 表示

| キー | 操作 |
| --- | --- |
| `V` | 視点をリセット |
| `G` | グリッド表示の切り替え |
| `E` | 地球表示の切り替え |
| `M` | ミニマップ（基準衛星の地上軌跡）の切り替え |
| `H` / `?` | ショートカット一覧を表示 |

## 衛星の選択中

| キー | 操作 |
| --- | --- |
| `T` | 推力付加フォームを開く |
| `P` | 位置変更フォームを開く |
| `↑` / `↓` | S 軸（Along-track）方向に ±0.001 m/s の速度変化を与える |
| `←` / `→` | R 軸（Radial）方向に ±0.001 m/s の速度変化を与える |
| `Shift` + `↑` / `↓` | W 軸（Cross-track）方向に ±0.001 m/s の速度変化を与える |
| `Esc` | 開いているフォームを閉じる。フォームがなければ選択を解除 |

## マウス・タッチ操作

| 操作 | 内容 |
| --- | --- |
| クリック / タップ | 衛星を選択 |
| ドラッグ | カメラを回転 |
| スクロール / ピンチ | ズーム |

## 実装

ヘルプに表示する一覧（`SHORTCUT_GROUPS`）とキー入力の処理（`useKeyboardShortcuts`）は、どちらも `src/features/help/shortcuts.ts` で定義しています。ショートカットを追加・変更するときは両方を更新してください。
