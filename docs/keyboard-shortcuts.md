# Keyboard Shortcuts

アプリ内では右上のキーボードアイコン、または **H** キーで一覧を表示できます。
入力欄にフォーカスがあるときはショートカットは無効になります。

## シミュレーション
- **Space** - 一時停止 / 再開
- **R** - 衛星を初期位置に戻す（CSV再生中は再生位置を先頭に戻す）
- **+** / **=** - 時間倍率を1段階上げる
- **-** / **_** - 時間倍率を1段階下げる
- **F** - シナリオ（フォーメーション）パネルを開く

## 表示
- **V** - カメラをリセット
- **G** - グリッド表示の切り替え
- **E** - 地球表示の切り替え
- **H** / **?** - キーボードショートカット一覧を表示

## 衛星選択時
- **T** - 推力付加フォームを開く
- **P** - 位置変更フォームを開く
- **↑ / ↓** - S軸（Along-track）方向に ±0.001 m/s
- **← / →** - R軸（Radial）方向に ±0.001 m/s
- **Shift + ↑ / ↓** - W軸（Cross-track）方向に ±0.001 m/s
- **Esc** - フォームを閉じる / 選択解除

## マウス
- **クリック** - 衛星を選択
- **ドラッグ** - カメラ回転
- **スクロール / ピンチ** - ズーム

一覧の定義は `src/features/help/shortcuts.ts`、処理は `src/hooks/useKeyboardShortcuts.ts` にあります。
