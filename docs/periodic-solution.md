# 周期解と積分定数

本書では、HCW 方程式の一般解を積分定数で表し、初期状態から積分定数を求める公式と、ドリフトのない周期解の条件をまとめる。座標系と方程式の前提は [HCW 方程式の理論](theory.md) と共通である。

## 1. 記法

座標系は Hill 座標系（LVLH）とする。

| 記号 | 意味 |
| --- | --- |
| $x$ | Radial（地球中心から基準衛星へ向かう方向） |
| $y$ | Along-track（軌道の進行方向） |
| $z$ | Cross-track（軌道面の法線方向） |
| $n$ | 基準軌道の平均運動 [rad/s] |

## 2. HCW 方程式

$$
\begin{aligned}
\ddot{x} - 2n\dot{y} - 3n^2 x &= 0\\
\ddot{y} + 2n\dot{x} &= 0\\
\ddot{z} + n^2 z &= 0
\end{aligned}
$$

## 3. 一般解

一般解は 6 個の積分定数 $A$–$F$ を用いて次のように表せる。

$$
\begin{aligned}
x(t) &= A \cos nt + B \sin nt + C\\
y(t) &= -2A \sin nt + 2B \cos nt - \tfrac{3}{2} n C t + D\\
z(t) &= E \cos nt + F \sin nt
\end{aligned}
$$

| 定数 | 役割 |
| --- | --- |
| $A$, $B$ | 面内の周期運動（2:1 楕円）の振幅と位相 |
| $C$ | Radial 方向のオフセット。Along-track 方向のドリフト $-\tfrac{3}{2}nCt$ を生む |
| $D$ | Along-track 方向のオフセット |
| $E$, $F$ | 面外の単振動の振幅と位相 |

### 3.1 周期解の条件

ドリフトを消すには $C = 0$ が必要十分である。このとき

$$
\begin{aligned}
x(t) &= A \cos nt + B \sin nt\\
y(t) &= -2A \sin nt + 2B \cos nt + D\\
z(t) &= E \cos nt + F \sin nt
\end{aligned}
$$

となり、相対軌道は周期 $2\pi/n$ で閉じる。

## 4. 初期状態から積分定数を求める

$t = 0$ における初期状態を $(x_0, y_0, z_0, \dot{x}_0, \dot{y}_0, \dot{z}_0)$ とすると、積分定数は次のとおりである。

| 定数 | 式 |
| --- | --- |
| $A$ | $x_0 - C = -3x_0 - 2\dot{y}_0/n$ |
| $B$ | $\dot{x}_0 / n$ |
| $C$ | $4x_0 + 2\dot{y}_0/n$ |
| $D$ | $y_0 - 2\dot{x}_0/n$ |
| $E$ | $z_0$ |
| $F$ | $\dot{z}_0 / n$ |

### 4.1 周期解のための初期状態の拘束

$C = 0$ を課すと、初期速度に次の拘束が生じる。

$$
\dot{y}_0 = -2nx_0
$$

このとき積分定数は

$$
A = x_0,\quad B = \frac{\dot{x}_0}{n},\quad D = y_0 - \frac{2\dot{x}_0}{n},\quad E = z_0,\quad F = \frac{\dot{z}_0}{n}
$$

となり、自由度は 5 に減る。

## 5. 導出

一般解に $t = 0$ を代入すると

$$
x_0 = A + C,\qquad y_0 = 2B + D,\qquad z_0 = E
$$

を得る。一般解を時間微分して $t = 0$ を代入すると

$$
\dot{x}_0 = nB,\qquad \dot{y}_0 = -2nA - \tfrac{3}{2}nC,\qquad \dot{z}_0 = nF
$$

を得る。この 6 本の連立 1 次方程式を解くと、

- $B$ と $F$ は初期速度から直ちに定まる。
- $A = x_0 - C$ を $\dot{y}_0$ の式に代入すると $\dot{y}_0 = -2nx_0 + \tfrac{1}{2}nC$ となり、$C = 4x_0 + 2\dot{y}_0/n$ を得る。
- $D = y_0 - 2B$、$E = z_0$。

$C = 0$ とおくと、4.1 節の拘束 $\dot{y}_0 = -2nx_0$ が得られる。

## 6. まとめ

- 一般解は 3 節の式で表され、$C$ がドリフトを決める。
- 周期解の条件は $C = 0$、すなわち $\dot{y}_0 = -2nx_0$ である。
- 初期状態から積分定数を求めるには 4 節の表を用いる。逆に、$A$–$F$ を指定すれば任意の周期軌道を設計できる（本アプリケーションの配置パターン「楕円軌道（係数指定）」はこの方法で衛星を配置する）。
